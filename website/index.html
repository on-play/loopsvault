Agent → vault → provider

Use secrets.
Never see them.

LoopsVault is a local encrypted vault for AI coding agents. The agent asks for an operation. The vault attaches the credential at the boundary. The value never enters the project process, terminal output, or model context.

Read the quick start ↗

A boundary, not a blindfold.

The agent gets the capability it needs and enough catalog context to choose it correctly. It does not receive ciphertext, a decryption key, or a hidden read path.

The mark

Two loops. One protected value.

Opposing loops form the operating boundary. The blue square is the credential: small, contained, and used without being exposed. The geometry remains legible as a favicon, menu-bar item, installer icon, or monochrome system glyph.
